        04 · Wire protocols & on-device security
        
Explicit adapters, private LAN pairing, and fail-closed keys

Private-LAN phone pairing walkthrough

          

            Entering a long API key on a watch keyboard is error-prone. Step through the 4-stage ephemeral local Wi-Fi handshake built in PairingServer, PhoneLauncher, and SecretStore, with 1-tap Open on phone, QR/URL setup, and encrypted phone-page model fetching (legacy NFC HCE removed).
          


          

            
            
            
            
          


          

            

            

            

          

        


        

          
Keystore encryption & linear edits

          

            Keys are encrypted inside SecretStore with a non-exportable Android Keystore AES-256-GCM key, version byte 1, 12-byte IV, and credentialRef AAD inside noBackupFilesDir. Transient Keystore IPC errors never destroy sibling profiles' keys, while permanent key invalidation fails closed and prompts re-entry rather than falling back to plaintext.
          

          

            Editing an earlier user message executes one Room transaction replacing that row and deleting all messages after it, keeping history strictly linear across switched providers.
          

          
Manifest: allowBackup="false" · usesCleartextTraffic="false" · FLAG_SECURE

          06 · Install & verify
          
Get NiroWear on your watch

          

            Needs Wear OS 3+ (minSdk 30), 32- or 64-bit ARM, 3.6 MB of storage, and a provider key you own, typed on the watch or sent from a phone on the same Wi-Fi. No account, no relay, no server of ours.
          


          

            
            
          


          

            

              Download app-release.apk from the latest GitHub Release and verify SHA-256 before installing. Builds 0.1.1 through 0.3.3 share CN=NiroWear Release and upgrade in place.

Engineering FAQ

          

            

              Why is Android cloud backup disabled?
              
API keys are encrypted under a non-exportable Keystore AES-256-GCM alias bound to that physical device. Restoring ciphertext onto another watch cannot decrypt without the hardware key, so allowBackup="false" stays enforced.

            

            

              Why store raw Markdown in Room instead of HTML?
              
Keeping canonical raw Markdown in Room messages lets parser, math, and table-layout improvements apply to historical conversations without migrating saved threads.

            

            

              Why do Markdown tables unwrap vertically?
              
Inside a 466 px circle, wide tables squash column headers and truncate digits. Emitting each row as a lazy record with repeated column labels keeps cells readable under vertical scroll.

            

            

              What happens if an endpoint has no /models route?
              
Model discovery and credential storage stay separate. Compatible providers accept any manually entered model ID and save offline even when discovery returns 404.
