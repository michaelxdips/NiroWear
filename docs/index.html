Replies parse into lazy headings, lists, horizontal code chunks, JLaTeXMath formulas, and vertical table records without cutting long answers.

    04 · Protocol contracts

    Four Adapters & Wire-Event Classification

    Model ID strings never pick the protocol. Each provider profile chooses an explicit wire adapter that checks HTTP headers, structured error payloads, and required SSE completion events.

    Endpoint
    Messages API · POST {base}/messages
    Auth header

    Top-level system field; adjacent same-role turns merged before dispatch
    Terminal event
    message_stop with verified stop reason (end_turn complete; max_tokens/pause_turn/tool_use surfaced as early truncation)
    Token metadata

          05 · Threat model & pairing protocol
          
    Keystore Encryption & Ephemeral Phone Pairing
    
          
    
            API keys never pass through a relay server, never touch cloud backup (allowBackup="false"), and never populate back into editing fields. Long keys move from phone to watch over a 120-second single-use HTTPS session.
          
    
        
    
      
    

      
    
        
    
          
    NFC Host Card Emulation
    
          
    Arms NfcPairingService with Type 2 NDEF URI tag bytes only during the 120 s window. Requests outside an armed session answer APDU 6A82.
    
          AIDs D2760000850101 · F001020304050607
        
    
        
    
          
    Integer-Scaled Watch QR
    
          
    ZXing encodes the ephemeral capability URL onto pixel-aligned modules (330 px at 466 dial, 248 px at 384), verified back via PairingQrTest pixel decode.
    
          Zero fractional half-pixel blur
        
    
        
    
          
    LAN URL / Manual Watch Entry
    
          
    Displays the short local https:// address on the dial for phones without camera/NFC, alongside full offline-capable manual key entry under FLAG_SECURE.
    
          Offline save never gated on validation

    Why keep backup disabled?
    
            
    API keys are AES-256-GCM encrypted using a hardware/device-bound Android Keystore alias. Backing up ciphertext without the Keystore key produces undecryptable state on another watch, so allowBackup="false" stays enforced.
    
          
    
          
    
            
    Why store raw Markdown instead of parsed HTML or JSON?
    
            
    Keeping raw USER and ASSISTANT Markdown in Room messages ensures future parser and JLaTeXMath improvements upgrade historical chats without any SQLite migration.
    
          
    
          
    
            
    Why do table rows repeat column headers?
    
            
    On a 28-character watch chord, multi-column grids squash headers and truncate numbers. Turning each table row into its own lazy vertical record keeps every cell crisp inside single-axis scrolling.
    
          
    
          
    
            
    Can compatible endpoints without /models still chat?
    
            
    Yes. Discovery and credential configuration stay decoupled: manual model ID entry and Save work offline, behind captive portals, and against endpoints that omit GET /models.
