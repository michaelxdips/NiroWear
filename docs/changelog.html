0.3.0 2026-11-26 Latest release

Atomic drafts, incremental streaming, TalkBack order, and 127-key parity

Exit-saved composer drafts live in Room (ChatDatabase v3) so Back-exit drafts survive process death and Send commits the question while clearing the draft in one transaction (InputResultUiTest).

  • Incremental Markdown streaming: adds ResponseParser.needsPreScan, container guards, ResponseParser.parseIncremental prefix caching (3,755 B cached on a 4 KB mixed answer), and single-flight parseDispatcher.
  • Localized unsaved banner & 127-key parity: moves the unsaved-answer notice under FailureToken.ANSWER_NOT_SAVED (failure_answer_not_saved), bringing values/ and values-in/ to 127 matching keys with zero missing or extra.
  • TalkBack order & code-block scroll cue: enforces top-to-bottom Menu -> Reader -> Footer traversal (TalkBackTraversalOrderTest) and adds a conditional horizontal-pan edge fade to code blocks (CodeBlockPanCueTest).
  • Workflow & CI gates: signed release builds gate keystore decode on ktlintCheck, testDebugUnitTest, lintDebug, and RELEASE_NOTES_0.3.0.md preflight; branch protection requires both jvm and instrumented.

0.2.2 2026-11-17

Stop button centering, Indonesian provider screen, and TextFieldValue preservation

Measured on the physical Xiaomi Watch 2: the Stop label sat at Rect(189,344,243,380) inside a button at Rect(161,314,305,410), 17 px left of center due to Compose Material 3 icon padding. Using a full-width centered label aligned it to dx = 0, dy = 0 (StopButtonCenterTest).

  • Full TextFieldValue retention: composer and edit body keep selection and composition state after Gboard was measured passing composition=(0,2). Issue #62 stayed open because lost-word reproduction failed under real taps.
  • End-to-end Indonesian provider UI (#66): changed Tambah compatible to Tambah kompatibel and moved provider hints into resources (125 keys per locale in 0.2.2).
